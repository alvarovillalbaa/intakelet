The host validates the authenticated actor/workspace and returns a matching acknowledgement. Progress never grants account permissions.

Install the SDK. Publish your integration.

Version 0.3.0 includes setup, quickstart, guided tours and reviewed file migration. Download the normal npm archive and install it in your Node 24+ application. React 18/19 wrappers and typed browser/Node entrypoints are included.

npm install ./alvarovillalbaa-intakelet-0.3.0.tgz

Connect your application handler and durable host, verify the installed consumers, then publish your own integration. The guides describe exports, acknowledgement events and deployment boundaries.

Keep any file type as an attachment, name your destination fields, and review resumable batches. Duplicate filenames stay separate.

This example keeps raw assets and destination records in memory in this tab: 2MiB per file and 8MiB of distinct assets, with no fixed file-count cap. Nothing is uploaded. Reloading clears this example; your application supplies durable storage. PDF, Office and image content is preserved as bytes.
